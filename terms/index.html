利用規約

IKUM株式会社（以下「当社」といいます。）が提供するオンラインレッスンおよび関連サービス（以下「本サービス」といいます。）の利用条件を以下のとおり定めます。

お客様は、本サービスに申し込みを行った時点で、本規約に同意したものとみなし、当社との間で利用契約が成立するものとします。

第1条（適用）

本規約は、本サービスの利用に関する当社とお客様との一切の関係に適用されます。

第2条（利用契約・登録）

1. お客様は、当社の定める方法により本サービスの利用登録を行うものとします。

2. 当社は、以下の場合に登録を拒否または取消すことがあります。

・虚偽の情報を申告した場合

・過去に規約違反があった場合

・その他当社が不適切と判断した場合

第3条（受講資格）

以下に該当する方は利用できません。

1. 医師により運動を禁止されている方

2. 感染症・感染性皮膚疾患のある方

3. 重度の既往症や怪我がある方（医師の許可がある場合を除く）

4. 未成年で保護者の同意がない方

5. 反社会的勢力に関係する方

6. その他当社が不適切と判断した方

第4条（健康管理・自己責任）

1. お客様は自己の健康状態を確認の上、自己責任において本サービスを利用するものとします。

2. 妊娠中・既往歴がある場合は、必ず医師の許可を得てください。

3. 本サービス利用により生じた事故・怪我について、当社は故意または重過失がない限り責任を負いません。

第5条（料金・支払い）

1. 本サービスは月額制のサブスクリプションサービスです。

2. 利用料金は当社が定める方法（クレジットカード決済等）により支払うものとします。

3. 本サービスは自動更新され、解約手続きが完了するまで継続されます。

4. 決済完了後の返金は、理由の如何を問わず行いません。

第6条（解約）

1. お客様は、当社所定の方法によりいつでも解約できます。

2. 解約後も、当該期間の終了まではサービス利用が可能です。

3. 解約のタイミングにより、次回決済が発生する場合があります。

4. 前各項の定めにかかわらず、当社が別途定めるキャンペーンプランまたは特別プラン（以下「特定プラン」といいます。）については、当該プランに定める契約期間および条件が優先して適用されます。

5. 特定プランは、一定期間の継続利用を前提とした特別価格での提供となるため、お客様のご都合により途中解約された場合であっても、契約期間満了までの利用料金の支払義務を負うものとします。また、当該特定プランにおいては、支払済みの料金については理由の如何を問わず返金はいたしかねますので、あらかじめご了承ください。

第7条（ポイント）

1. ポイントの有効期限は付与日より2年間とします。

2. 解約時にはポイントは消滅します。

3. ポイントは当社指定の用途にのみ利用可能です。

4. 1回の決済におけるポイント使用上限は2,000ポイントとします。

5. 1回当たりのポイント利用単位は500ポイントとします。

6. お客様が本レッスンの受講料等のお支払いにポイント利用の申請をした時点で、当該決済は確定となり、いかなる理由があってもキャンセル・変更・返金はできません。

第8条（禁止事項）

・無断転載・録画・配信

・商用利用

・他者へのアカウント共有

・サービス運営妨害

・その他当社が不適切と判断する行為

第9条（サービスの停止・変更）

当社は以下の場合、サービスを停止・変更できるものとします。

・システム障害

・天災

・運営上の必要

・その他不可抗力

第10条（受講資格の喪失）

以下の場合、利用資格を停止・取消できます。

・規約違反

・支払い遅延

・不正利用

・その他当社が不適切と判断

第１１条（遅延損害金）

1. お客様が、本レッスンの受講料金その他本規約に基づく金銭債務を支払期日までに支払わなかった場合、当社は、お客様に対する本レッスンの提供を停止し、または利用契約を解除することができます。

2. お客様は、支払期日の翌日から支払済みまで、年14.6％の割合による遅延損害金を支払うものとします。

第１２条（損害賠償）

1. お客様が、本規約に違反し、または自己の責に帰すべき事由により、当社または第三者に損害を与えた場合、お客様はその一切の損害（合理的な弁護士費用を含みます。）を賠償するものとします。

2. お客様による本規約違反行為に起因して、当社が第三者から請求、異議、訴えその他の紛争の提起を受けた場合、お客様は、自己の責任と費用においてこれを解決し、当社に損害が生じた場合にはこれを賠償するものとします。

第13条（責任の制限）

1. 当社は、当社の故意または重過失がある場合を除き、お客様に現実に生じた通常かつ直接の損害を賠償するものとします。この場合の、当該賠償の累計総額は、当該損害の発生日から起算して過去12ヶ月間にお客様が当社に支払った本レッスンの受講料金の総額を限度とします。

2. 前項の範囲をもって当社の軽過失に基づく補償及び賠償責任の限度とし、当社の責に帰すことのできない事由から生じた損害、当社の予見の有無を問わず特別の事情から生じた損害、逸失利益については責任を負わないものとします。

3. 前2項の定めは、当社に故意・重過失が認められる場合は、適用されません。

4. 当社は、以下のいずれについてもいかなる表明保証も行わず、責任を負いません。

(1) 本レッスンの受講に起因するお客様のコンピュータシステムへの損害、データの消失その他の損害

(2) 本レッスンの内容がお客様の要求を満たすかどうか、また中断されることなく、安全に、もしくはエラーなく受講できるかどうか

5. これらに関してお客様に損害が生じた場合、当社に故意・重過失がある場合を除き、当該賠償の累計総額は、当該損害の発生日から起算して過去12ヶ月間にお客様が当社に支払った本レッスンの受講料金の総額を限度とします。

第14条（知的財産権）

本サービスに含まれるコンテンツの著作権は当社に帰属し、無断利用を禁止します。

第15条（規約の変更）

当社は必要に応じて本規約を変更できるものとし、変更後は公表時点より効力を有します。

第16条（準拠法・管轄）

本規約は日本法に準拠し、東京地方裁判所を専属管轄とします。
